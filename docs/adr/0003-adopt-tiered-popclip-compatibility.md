# Adopt tiered PopClip compatibility

Spinnet will import original PopClip packages through named Compatibility Levels and produce a Compatibility Report for each package, prioritizing extension patterns with low adaptation cost and broad reuse rather than promising full behavioral equivalence. This preserves access to existing user assets and should make a large portion of the ecosystem structurally convertible without committing Spinnet to reproduce every dynamic action, JavaScript API, host behavior, or future PopClip change.
